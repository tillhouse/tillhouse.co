# Verdancy.ai

**Role:** Co-Founder & Head of Product  
**Company:** Moonfoot Labs  
**Status:** Launched

## Overview
Verdancy.ai is an embedded user research and analytics agent for Claude Code and other AI coding agents.

AI coding tools have made building fast, but learning what users actually think is still slow. Verdancy closes that loop inside the developer's existing workflow:
- A small widget in the app asks real users short questions, each tied to a product hypothesis.
- The app reports events that test those hypotheses.
- The developer's coding agent reads the answers and numbers, proposes changes in the codebase, and records what it did.

## My role
I lead product for Verdancy at Moonfoot Labs: strategy, discovery, validation, prioritization, and go-to-market planning. I also build it hands-on with Claude Code, Codex, Cursor, Next.js, Supabase, and Vercel.

## Dogfooding
This site runs Verdancy. The short questions you may see while browsing tillhouse.co come from it, and they shape how the site changes.
